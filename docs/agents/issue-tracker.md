# Issue tracker

Use `docs/backlog.md` for unresolved work spanning sessions.
Follow the backlog lifecycle rules in root `AGENTS.md`.

When a skill asks to publish or fetch a ticket, write or read
the relevant backlog entry. Give each entry a stable identifier
and record its scope, status, blockers and completion evidence.

Record triage labels in a `Triage:` field using
`docs/agents/triage-labels.md`. Keep execution status separate.

Create the backlog only when qualifying unresolved work exists.
