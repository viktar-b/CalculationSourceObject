# Triage labels

Use these strings in each backlog entry's `Triage:` field.

| Role and label | Meaning |
| --- | --- |
| needs-triage | Needs maintainer evaluation |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be pursued |
