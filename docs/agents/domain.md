# Domain docs

Use one shared root `CONTEXT.md` and `docs/adr/` across packages.

Before exploring the codebase, read `CONTEXT.md` and the ADRs
relevant to the work. Follow the additional reading requirements
in root `AGENTS.md`.

If a domain document is absent, proceed without creating a
placeholder.

Use the glossary's terms consistently. Flag missing concepts
when relevant and state explicitly when a proposal conflicts
with an accepted ADR.
